# Seeder

Seeders are handled by the `roolith/migration` package (`^2.0`) through `App\Database\MigrationFactory`. Seeder files live in `database/seeders` as `*.seeder.php` and applied names are tracked in the shared `migrations` status table (`file_type = 'seeder'`) so seed data never duplicates between deploys.

## Commands

Run from the project root:

```bash
php roolith seed:create add_users
php roolith seed
php roolith seed:status
php roolith seed:run
php roolith seed:run add_users
```

- `seed:create <Name>` scaffolds `database/seeders/<timestamp>_<rand>_<Slug>.seeder.php` with a `run()` skeleton. The directory is created when missing and the name includes a timestamp plus random suffix so concurrent creates never collide. `seeder:create` is an accepted alias.
- `seed [Name]` runs pending seeders in filename order, or one named seeder when given (full timestamped name or short logical name). A failing seeder marks its row `failed` and the rest still run.
- `seed:run [Name]` runs all pending seeders, or one named seeder when given (full timestamped name or short logical name). `seeder:run` is an accepted alias with the same behavior.
- `seed:status [Name]` lists seeder rows with their status. `seeder:status` is an accepted alias. There is intentionally no seeder rollback; seed data is generally non-reversible.

## Seeder files

```bash
php roolith seed:create add_users
```

```php
<?php

use Roolith\Migration\Interfaces\SeederInterface;
use Roolith\Store\Interfaces\DatabaseInterface;

class _Seeder_20250908120000_ab12_AddUsers implements SeederInterface
{
    /**
     * Run the seeder.
     *
     * @param DatabaseInterface $db Shared database connection.
     * @return void
     */
    public function run(DatabaseInterface $db): void
    {
    }
}
```

Inside `run()` you get the [database](/database) connection, so every driver method from the [database](/database) page is available on `$db`.

    {

## Notes

- The shared `migrations` status table also tracks seeders (`file_type = 'seeder'`); it is created automatically when missing. The legacy `seeds` table from the old internal runner is no longer written.
- Only `*.seeder.php` files in `database/seeders` run. Commands accept the full timestamped name or the short logical name; ambiguous short names ask for the full name.
- Names allow letters, numbers, underscore, and hyphen; paths, `..` traversal, and null bytes are rejected before touching the filesystem. A missing file, missing class, or class not implementing `SeederInterface` fails the row instead of crashing the batch.
- Class names are generated by the package (`_Seeder_<timestamp>_<rand>_<Name>`); `App\Database\SeederInterface` remains as a BC alias.
- Seeders run via `roolith/migration` through `App\Database\MigrationFactory` with `php roolith seed`, `seed:status`, `seed:create`, `seed:run` (plus `seeder:*` aliases) commands.
