# Roolith Framework - Audit TODO

Scope: `ARCHITECTURE.md`, `README.md`, plus code verification of `index.php`, `constant.php`, `config/config.php`, `app/Core/*`, `app/Utils/*`, `app/Http/routes.php`, `app/Controllers/*`, `app/Models/*`, `Dockerfile`, `docker-compose.yml`, `.htaccess`, `vite.config.mjs`, `composer.json`, `.github/workflows/*`. Goal: list problems by category with concrete fixes in small verifiable steps. Check off items as they are fixed with a test or manual verification note.

Severity legend: Critical = exploitable or data loss or prod outage risk. High = likely bug or security weakness. Medium = maintainability, DX, or edge-case correctness. Low = polish, docs, or minor hardening.

Summary: Security has the most Critical items (fail-open env, LFI via lang cookie, Host header handling, upload validation, missing CSRF/auth). Reliability has the most High items (exits skipping cleanup, destructive input sanitization, validator edge cases, silent config nulls). Architecture/Test/Ops items are mostly Medium but block long-term maintainability (statics/singletons, no tests, no logging, no env support).
